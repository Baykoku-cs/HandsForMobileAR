GestureRecognition = 1

This mode uses Gesture Recognition model that is enhanced version of Hand Landmark model. Adds embeding and classification models into computation pipeline.

LandmarksOnly = 0

There will be only Hand Landmark model running. So there will be no gesture-related date. You can use this to improve application performance in case you don't need gestures.
