## Hands For Mobile AR
This is a Unity plugin (or library), that you can use to add hand tracking into your project! 
This solution based on [MediaPipeUnityPlugin](https://github.com/homuler/MediaPipeUnityPlugin).

## Краткое описание проекта
Проект представляет собой библиотеку для *Unity*, реализующую связку *MediaPipe* и *ARFoundation* и предназначенную для трекинга рук в AR-приложениях реального времени.

Основная задача проекта - забрать на себя всю работу с *MediaPipe*, оставив разработчикам удобный интерфейс, привычный при работе с *Unity*.

Проект будет полезен всем разработчикам иммерсивных AR-приложений на Unity, желающим быстро добавить трекинг рук без погружения в детали интеграции MediaPipe и ARFoundation.

## Технологический стек проекта
**Языки:** C#

**Фреймворки и библиотеки:**
- Unity Engine (игровой движок)
- ARFoundation (фреймворк дополненной реальности)
- MediaPipeUnityPlugin (перепись MediaPipe с C++ на C# для Unity)
